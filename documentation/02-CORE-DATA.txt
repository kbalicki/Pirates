1. STATKI (ships.ts)
--------------------------------------------------------------------------------
  5 klas statków, każda z następującymi parametrami:

  ShipClassDef {
    id:        ShipClassId       — identyfikator klasy
    name:      string            — nazwa wyświetlana
    speedBase: number            — bazowa prędkość (units/tick)
    turnRate:  number            — szybkość skrętu (rad/tick)
    hullMax:   number            — max HP kadłuba
    sailsMax:  number            — max HP żagli
    cannons:   number            — liczba dział
    cargoCap:  number            — pojemność ładowni (units)
    crewMax:   number            — max załoga
    crewMin:   number            — min załoga do obsługi
    buyPrice:  number            — cena kupna (złoto)
    sprite:    string            — klucz sprite'a

2. PORTY / MIASTA (cities.ts)
--------------------------------------------------------------------------------
  45 miast karaibskich rozmieszczonych na mapie 3200×2400.

  CityDef {
    id:            PortId
    name:          string
    factionId:     FactionId         — właściciel (spain/england/france/netherlands)
    type:          "city"|"fort"|"outpost"
    pos:           Vec2              — pozycja na mapie świata
    dockRadius:    number            — promień dokowania (32-44 units)
    marketLevel:   number            — poziom rynku (1-5)
    shipyardLevel: number            — poziom stoczni (1-4)
    produces:      string[]          — produkowane towary
    demands:       string[]          — poszukiwane towary
    population:    "small"|"medium"|"large"|"capital"
    wealth:        "poor"|"modest"|"prosperous"|"wealthy"
  }

  Podział frakcji:
    Hiszpania (22):  Havana, Santiago, Cartagena, Panama, Vera Cruz,
                     Santo Domingo, San Juan, Trinidad, Campeche, Portobelo,
                     Maracaibo, Cumana, Margarita, Santa Marta, Nombre de Dios,
                     Honduras, Merida, Caracas, Gibraltar, Rio de la Hacha,
                     Santa Catalina, Santiago de Cuba
    Anglia (10):     Port Royal, Nassau, Barbados, Antigua, Bermuda,
                     St Kitts, Nevis, Montserrat, Grand Cayman, Belize
    Francja (8):     Tortuga, Martinique, Guadeloupe, Petit Goave,
                     Port de Paix, Leogane, St Martin FR, Grenada
    Holandia (3):    Curaçao, St Eustatius, St Martin NL

  System współrzędnych (przeliczenie z lon/lat):
    x = (98 - longitude) / 40 * 3200
    y = (30 - latitude)  / 23 * 2400

5. DYNAMICZNE CENY (prices.ts)
--------------------------------------------------------------------------------
  System cen zależy od:
  - Baza: basePrice z ItemDef
  - Produkcja: × 0.7 jeśli port produkuje towar (PRODUCE_MODIFIER)
  - Popyt:     × 1.4 jeśli port potrzebuje towaru (DEMAND_MODIFIER)
  - Rynek:     × (0.9 + marketLevel × 0.05)
  - Bogactwo:  wpływa na ilość inwentarza (poor: ×0.5, wealthy: ×1.5)

  Funkcje:
    getBasePrice(portDef, itemDef) → number
    initPortPrices(rng, portDef)  → Record<ItemId, number>
    initPortInventory(rng, portDef) → Record<ItemId, number>

7. RANGI (ranks.ts)
--------------------------------------------------------------------------------
  Każda frakcja ma 6 rang (indeks 0-5):
    0: brak rangi

  Funkcja: getRankNameKey(factionKey, rankIndex) → klucz i18n
  Przykład: getRankNameKey("spain", 3) → "rank.spain.3"

9. STREFY MAPY (mapZones.ts)
--------------------------------------------------------------------------------
  Strategiczne strefy z ryzykiem i wiatrem:

  MapZoneDef {
    zoneId:             string
    kind:               "piracy"|"patrol"|"trade_wind"|"storm_prone"
    risk:               number         — 0..1 (prawdopodobieństwo encounter)
    rect:               { x, y, w, h } — prostokąt strefy
    windDirBias?:       number         — kierunek wiatru (radiany)
    windStrengthBias?:  number
    factionId?:         FactionId
  }

  Strefy:
    Windward Passage  — piracy, risk 0.6
    Spanish Main      — patrol, risk 0.3
    Trade Winds       — trade_wind, risk 0.1
    Hurricane Alley   — storm_prone, risk 0.4
    Straits of Florida — patrol, risk 0.25

10. WIATR SEZONOWY (wind.ts)
--------------------------------------------------------------------------------
  12 konfiguracji miesięcznych (karaibski cykl pogodowy):

  MonthlyWindConfig {
    baseDirection:      number    — kierunek bazowy (0..2π)
    baseStrength:       number    — siła bazowa (0..1)
    directionVariance:  number    — wariancja kierunku
    strengthVariance:   number    — wariancja siły
    stormChancePerTick: number    — szansa na burzę
  }

  Sezonowość:
    Zima (sty-mar): Pasaty NE, umiarkowane, mało burz
    Wiosna (kwi-maj): Pasaty E, łagodne
    Lato (cze-sie): E-ESE, sezon huraganowy (szczyt: sie-wrz)
    Jesień (wrz-lis): Malejące wiatry, ostatnie huragany

  Szansa na burzę: 0.000020 (styczeń) → 0.000120 (wrzesień)
