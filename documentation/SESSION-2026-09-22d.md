# Sesja 2026-09-22d — v0.88.0.0 → v0.89.0.0

**Pozycja 1 z listy brzmiała: „czy reguła mieści się w świecie, w którym
działa?". Pierwsza reguła wzięta z tabeli `px` odpowiedziała: nie mieści się
wcale. Mgła — mechanika napisana jako schronienie dla ściganego kapitana, z
własnym akapitem tłumaczącym, dlaczego jest dla niego łaskawsza niż dla
pogoni — nie powstała w ciągu 54 dób symulacji ani razu.**

## 1. Trzy warunki, z których pierwszy nie zachodzi

Mgła potrzebuje trzech rzeczy naraz: ciszy, małych godzin i ławy akurat tam,
gdzie jesteś.

```ts
/** Above this wind there is no fog, whatever the hour. */
export const FOG_MAX_WIND = 0.35;
```

A `updateWeather` robi morze, którego `windStrength`:

| | |
|---|---|
| średnia | **0,543** |
| najniższa wartość w 27 000 próbek (54 doby) | **0,174** |
| próg, poniżej którego mgła w ogóle zaczyna istnieć | **0,35** |

| | |
|---|---|
| próbek dość cichych, żeby mgła mogła być | **40 z 27 000 (0,15 %)** |
| próbek w godzinach mgły (22:00–10:00) | 13 158 (48,7 %) |
| próbek z **mgłą zgłoszoną** (`≥ FOG_VISIBLE`) | **0** |

Zegar jest w porządku. Bramką jest wiatr — **próg ustawiony poniżej podłogi
rzeczy, którą bramkuje, nie jest rzadkim zdarzeniem, tylko wyłącznikiem.**

## 2. Drugi ogranicznik: iloczyn, który nie umie dać jedynki

```ts
return calm * hour * patch;
```

Oba udziały, które ten wynik czytają, są pisane dla gęstości **1**:

> `FOG_VISION_SHARE = 0.35` — *„what is left of the spyglass in a **thick
> bank**"*
> `FOG_AWARENESS_SHARE = 0.45` — *„what is left of an NPC's lookout in **the
> same bank**"*

Tylko że pole szumu to dwuliniowa mieszanka czterech haszów, a taka mieszanka
zbiera się wokół połowy i nie sięga swoich końców:

| | |
|---|---|
| średnia surowego pola | **0,492** |
| najwyższa wartość w 13 158 próbek nocnych | **0,837** |
| `FOG_PATCH_FLOOR` | **0,55** |

Normalizacja `(raw − 0,55) / (1 − 0,55)` daje w **najlepszej komórce Karaibów**
wartość **0,64** — a iloczyn trzech takich czynników nie osiągnie jedynki
**z konstrukcji**. Przemiotłem każdy próg wiatru od 0,35 do 1,0:

| próg wiatru | podłoga 0,55 | 0,45 | 0,35 | 0,25 |
|---|---|---|---|---|
| 0,35 | 0,0 % · max 0,00 | 0,0 % · 0,00 | 0,0 % · 0,00 | 0,0 % · 0,02 |
| 0,55 | 0,0 % · 0,12 | 0,0 % · 0,13 | 0,0 % · 0,14 | 0,0 % · 0,14 |
| 0,65 | 0,8 % · 0,20 | 1,5 % · 0,22 | 3,4 % · 0,23 | 6,4 % · 0,24 |
| 0,75 | 3,9 % · 0,26 | 10,5 % · 0,28 | 18,1 % · 0,30 | **24,8 % · 0,32** |

**Najgrubsza ława, jaką dało się wycisnąć z czegokolwiek: 0,32.**

Więc próg wiatru bierze się teraz z wiatru, który świat naprawdę robi, a pole
normalizuje się **między podłogą pod własną średnią a sufitem na własnym
szczycie** — i wtedy rozpina to, co twierdzi, że rozpina.

| | przed | po |
|---|---|---|
| `FOG_MAX_WIND` | 0,35 | **0,75** |
| `FOG_PATCH_FLOOR` | 0,55 | **0,35** |
| `FOG_PATCH_CEIL` | — (dzielone przez 1) | **0,80** |
| mgła zgłoszona | **0 %** próbek | **14,3 %** |
| najgrubsza ława | **0,00** | **0,40** |
| luneta kapitana | 49,2 zawsze | 48,8 w czystym / **43,0** w ławie |

## 3. I oślepiała wszystkich prócz tych dwóch, którzy go ścigają

```ts
/**
 * `awarenessRadius` is what she can see in clear air; fog takes a share of it
 * off. (…) It is deliberately the same field read four times rather than four
 * separate rules: whatever "she noticed him" means, it should mean the same
 * thing to a merchantman, a navy sloop, an escort and a named ship's consort.
 */
function awarenessIn(world, entity) { … }
```

Korsarza i łowcy piratów **nie ma na tej liście**. Czytały płaskie
`PIRATE_CHASE_RADIUS = 200` i `HUNTER_CHASE_RADIUS = 250` — więc mgła nie
zabierała nic oczom **jedynych statków, przed którymi jest napisana, żeby go
ukryć**. A `FOG_AWARENESS_SHARE` mówi wprost: *„he is the one being hunted
often enough for this to be the half he notices"*.

**Mechaniczny powód jest jedną linijką.** Z czterech zachowań tylko jedno nie
dostawało `world`:

```ts
case "trader":        return updateTrader(entity, player, dist, world, rng);
case "navy":          return updateNavy(entity, player, dist, world, rng);
case "pirate":        return updatePirate(entity, player, dist, rng);        // ←
case "pirate_hunter": return updatePirateHunter(entity, player, dist, world, rng);
```

`updatePirate` **nie mogło** przeczytać reguły mgły, bo nie miało z czego.
`updatePirateHunter` miało i i tak czytało płaską liczbę.

Do tego te dwie liczby były **drugą kopią**: szablony spawnu dają korsarzowi
`awarenessRadius` 250, a łowcy 300, i płaskie 200/250 je nadpisywały. Teraz
jedna liczba na kadłub, w tabeli, która go opisuje.

## 5. Strażnicy

Siedem nowych asercji w `FogSystem.test.ts`, i **każda jest pomiarem**:

- **próg wiatru musi stać powyżej własnej średniej morza** — `FOG_MAX_WIND >
  0,543`, a `fogCalmFactor` przy tej średniej > 0,2 i przy zmierzonym minimum
  > 0,7;
- **gęstość musi umieć dojść do jedynki**, którą opisują oba udziały:
  `FOG_PATCH_CEIL ≤ 0,837` (zmierzony szczyt pola), `FOG_PATCH_FLOOR < 0,492`
  (zmierzona średnia), a w ciszy, o czwartej, w szczycie ławy iloczyn = **1**;
- **rover i łowca tracą w ławie zasięg, który ława im zabiera** — po jednym
  teście na zachowanie, plus para „a z burty i tak go dopadnie";
- **w `NpcAiSystem` nie ma już żadnego płaskiego promienia pościgu**.

## 7. Co z tego zostaje

- **Próg ustawiony poniżej podłogi rzeczy, którą bramkuje, jest wyłącznikiem, a
  nie rzadkim zdarzeniem.** 0,35 przeciwko wiatrowi, który nigdy nie zszedł
  poniżej 0,174.
- **Iloczyn trzech czynników nie osiąga jedynki, a stała czytająca go mówiła
  „a thick bank".** Jeśli liczba opisuje przypadek skrajny, trzeba sprawdzić,
  czy generator go produkuje — pole szumu ma szczyt 0,837, nie 1.
- **Reguła, która wymienia swoich czytelników w komentarzu, wymienia ich po to,
  żeby ktoś policzył.** Czterech wymienionych, dwóch najważniejszych poza listą.
- **Parametr, którego funkcja nie dostaje, jest regułą, której nie może
  przeczytać.** `updatePirate` było jedynym z czterech bez `world` — i jedynym,
  którego mgła nie dotyczyła.
- To jest pierwsza pozycja przejścia tabeli `px` pod kątem *wzrok / zasięg /
  obecność*. Zostały `PRESENCE_RANGE` (400) i `BLOCKADE_RADIUS` (320).
